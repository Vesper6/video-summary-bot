    快速上手

    1. 配置 Claude API：设置 ANTHROPIC_API_KEY（或 ANTHROPIC_AUTH_TOKEN）环境变量
    2. 安装 yt-dlp：pip install yt-dlp
    3. 「视频总结」页粘贴视频链接，点击开始总结
    4. B 站 / YouTube 登录内容：用浏览器插件导出 cookies.txt 放到程序目录

    虚拟机（micro VM）

    1. 准备 guest 镜像：bash scripts/prepare-guest.sh + bash scripts/quick-rootfs.sh
    2. Windows 构建：cargo build --release --features whvp；Linux：--features kvm
    3. 「虚拟机」页新建并启动 VM，「控制台」标签实时查看内核串口日志
    4. CLI 等价命令：vsb vm create / start / logs / stop

    常用命令

    vsb doctor all                       # 健康检查
vsb summarize --url "…"              # 命令行总结
vsb vm boot                          # 端到端 VM 启动验证
vsb serve --port 8080                # 启动 HTTP API
